# HP Prime Apps & Programs
**Resumen:** Este repositorio contiene diversos programas diseñados para la HP Prime G2 focalizados en diversos ámbitos principalmente relacionados con la ingeniería mecánica y electrónica.

Estos programas fueron programados como recurso durante mi aprendizaje de las dos carreras previamente mencionadas, por lo que en algunos casos se encuentran incompletos o son poco intuitivos. No se van a realizar actualizaciones, ni modificaciones de los mismos una vez hayan sido publicados, a no ser que vuelva a precisar de ellos.
